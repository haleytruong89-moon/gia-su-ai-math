## Cách 1 — Tích bằng 0
<!-- máy kiểm, con không thấy
số: 6, 5
kiểm: (2*3 - 6)*(3 + 5) == 0
kiểm: (2*(-5) - 6)*(-5 + 5) == 0
kiểm: 4**2 == 4*4
-->

**Ví dụ.** Giải phương trình (2x − 6)(x + 5) = 0.

**Vì sao tách được?** Hai số nhân với nhau bằng 0 thì **ít nhất một số phải bằng 0** (số khác 0 nhân số khác 0 không thể ra 0). Vậy:

- 2x − 6 = 0 → **x = 3**, hoặc
- x + 5 = 0 → **x = −5**.

Phương trình có hai nghiệm x = 3 và x = −5.

**Lỗi hay gặp — chia cho ẩn.** Giải x² = 4x mà chia cả hai vế cho x được x = 4 là **mất nghiệm x = 0** (vì không được chia cho một số có thể bằng 0). Đúng là: x² − 4x = 0 → x(x − 4) = 0 → x = 0 hoặc x = 4.

📝 **Mẹo nhớ:** *Đưa hết về một vế, vế kia bằng 0, rồi phân tích thành tích.* Vì: chỉ khi vế phải là 0 mới dùng được tính chất "tích bằng 0".

🔎 **Ghi vào vở:** Không bao giờ chia hai vế cho biểu thức chứa ẩn. Muốn "bỏ" nó thì **đặt nhân tử chung**.

## Cách 2 — Ẩn ở mẫu: ĐKXĐ là hàng rào
<!-- máy kiểm, con không thấy
số: 3, 2
kiểm: 2/(3 + 1) == 1/(3 - 1)
kiểm: 2 + 1 == 3
-->

**Ví dụ.** Giải: a) 2/(x + 1) = 1/(x − 1); b) (x + 1)/(x − 2) = 3/(x − 2).

**Bước 1 — ĐKXĐ trước tiên.** Mẫu không được bằng 0.

- a) x + 1 ≠ 0 và x − 1 ≠ 0 → **x ≠ −1, x ≠ 1**.
- b) x − 2 ≠ 0 → **x ≠ 2**.

**Bước 2 — Quy đồng, khử mẫu, giải.**

- a) 2(x − 1) = x + 1 → 2x − 2 = x + 1 → x = 3.
- b) x + 1 = 3 → x = 2.

**Bước 3 — Đối chiếu ĐKXĐ.**

- a) x = 3 thỏa mãn ĐKXĐ → nghiệm **x = 3**. Thử: 2/4 = 1/2 ✓.
- b) x = 2 **vi phạm** ĐKXĐ (làm mẫu bằng 0) → loại. Phương trình **vô nghiệm**.

**Vì sao phải đối chiếu?** Lúc khử mẫu, ta đã nhân hai vế với biểu thức chứa x. Phép nhân đó có thể "đẻ" ra giá trị làm mẫu bằng 0 — giá trị ấy không thay được vào đề ban đầu.

📝 **Mẹo nhớ:** *ĐKXĐ viết trước, đối chiếu viết sau.* Vì: ĐKXĐ là hàng rào; nghiệm nào nằm ngoài hàng rào thì phải loại.

🔎 **Ghi vào vở:** Kết luận phải nói rõ: "x = 2 không thỏa mãn ĐKXĐ, phương trình vô nghiệm". Thiếu câu này là thiếu bước.
