## Cách 1 — Nhận ra hằng đẳng thức trong căn
<!-- máy kiểm, con không thấy
số: 16, 4
kiểm: simplify(1/(sqrt(x) - 4) - 8/(x - 16) - 1/(sqrt(x) + 4)) == 0
kiểm: simplify((x - 16) - (sqrt(x) - 4)*(sqrt(x) + 4)) == 0
kiểm: (1/(sqrt(x) + 4)).subs(x, 9) == Rational(1, 7)
-->

**Ví dụ.** Rút gọn C = 1/(√x − 4) − 8/(x − 16).

**Rút gọn là gì?** Viết biểu thức cho **gọn nhất** mà **giá trị không đổi** với mọi x hợp lệ. Thử x = 9: biểu thức ban đầu bằng 1/7, và biểu thức sau khi rút gọn cũng phải ra 1/7.

**Bước 1 — ĐKXĐ (vì sao phải có?).** Căn của số âm không có nghĩa, và không được chia cho 0. Nên x ≥ 0 và x ≠ 16. **ĐKXĐ: x ≥ 0, x ≠ 16.**

**Bước 2 — Nhìn ra "bí mật" của mẫu.** Khi x ≥ 0 thì x = (√x)². Nên x − 16 = (√x)² − 4² = (√x − 4)(√x + 4). Đây chính là hằng đẳng thức a² − b² = (a − b)(a + b) của lớp 8, chỉ là a = √x.

**Bước 3 — Quy đồng.** Mẫu chung là (√x − 4)(√x + 4):
C = (√x + 4 − 8) / ((√x − 4)(√x + 4)) = (√x − 4) / ((√x − 4)(√x + 4)).

**Bước 4 — Rút gọn đến tận cùng.** Tử và mẫu cùng có (√x − 4) → gạch đi: **C = 1/(√x + 4)** với x ≥ 0, x ≠ 16. Kiểm lại với x = 9: 1/(3 + 4) = 1/7 ✓.

📝 **Mẹo nhớ:** *Thấy "x trừ số chính phương" → nghĩ ngay (√x − a)(√x + a).* Vì sao nhớ được: với x ≥ 0 thì x = (√x)², nên x − a² là hiệu hai bình phương.

🔎 **Ghi vào vở — thói quen tự soát:** ① Viết ĐKXĐ trước. ② Phân tích mẫu. ③ Thu gọn tử. ④ Tử và mẫu còn nhân tử chung không? ⑤ Thử một giá trị x để kiểm.

## Cách 2 — Đặt t = √x: bài căn thành bài phân thức lớp 8
<!-- máy kiểm, con không thấy
số: 36, 6
kiểm: simplify(1/(t - 6) - 12/(t**2 - 36) - 1/(t + 6)) == 0
kiểm: simplify(1/(sqrt(x) - 6) - 12/(x - 36) - 1/(sqrt(x) + 6)) == 0
-->

**Ví dụ.** Rút gọn D = 1/(√x − 6) − 12/(x − 36).

**Vì sao làm được?** Căn chỉ là "lớp áo" bên ngoài. Đặt **t = √x** (nhớ t ≥ 0). Vì x = t² nên D = 1/(t − 6) − 12/(t² − 36). Giờ nó là **phân thức đại số lớp 8** em đã quen!

**Làm như lớp 8.** t² − 36 = (t − 6)(t + 6).
D = (t + 6 − 12) / ((t − 6)(t + 6)) = (t − 6) / ((t − 6)(t + 6)) = 1/(t + 6) (với t ≠ 6).

**Mặc lại "lớp áo".** Thay t = √x: **D = 1/(√x + 6)**. Điều kiện t ≥ 0, t ≠ 6 nghĩa là x ≥ 0, x ≠ 36.

📝 **Mẹo nhớ:** *Rối vì căn → đặt t = √x (t ≥ 0) → làm như phân thức lớp 8 → thay lại.* Vì sao nhớ được: khi t = √x thì x = t², nên chỗ nào có x đều thay được bằng t².

🔎 **Ghi vào vở — khi nào dùng:** biểu thức có cả √x và x (như x − 36, x + 4√x + 4, x − 2√x). Nếu thấy hằng đẳng thức ngay thì không cần đặt t.
