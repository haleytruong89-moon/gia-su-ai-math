# G3 — Ảnh đề bài (và ảnh bài làm) · Implementation Plan

> **For agentic workers:** Implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Con chụp hoặc chọn ảnh đề, cô đọc ảnh và xác nhận đề. Ảnh có nhiều bài thì cô hỏi "em đang làm bài số mấy". Giữa bài, con gửi được ảnh bài làm. Ảnh đã xóa EXIF, đã thu nhỏ, cất private trong Storage.

**Architecture:**
- **Trình duyệt** thu nhỏ ảnh (canvas, cạnh dài ≤ 2048 px, JPEG). Bước này vừa bỏ EXIF lần 1 vừa giữ body < 4 MB, dưới giới hạn 4,5 MB của Vercel.
- **Máy chủ** (`sharp`) đọc lại ảnh, xoay theo EXIF, bỏ mọi metadata, thu về cỡ chuẩn của Claude (≤ 1568 px, ≤ 1568 token hình), rồi lưu JPEG q80 vào bucket private `tutor-images`.
- **Mỗi lượt**, máy chủ tải lại ảnh của bài và gắn vào đúng tin của con trong lịch sử. Cache breakpoint thứ 4 đặt ở ảnh cuối cùng, nên từ lượt 2 trở đi ảnh được đọc từ cache.
- Bộ kiểm tra Haiku cũng thấy **ảnh đề** khi đề chưa được xác nhận bằng chữ.
- Khi con xác nhận đề, máy chủ chép lời cô đọc đề vào `problems.confirmed_statement`. Từ đó guard, báo cáo và việc xóa ảnh sau 90 ngày đều dựa vào chữ này.

**Tech Stack:** Next.js 16 route handlers (multipart `formData()`), `sharp`, Supabase Storage (service role, URL ký 10 phút), Anthropic image blocks (base64), Vitest, Playwright.

**Spec:**
- `docs/DOMAIN.md` §2 (bảng `attachments`, quyền), §4.8 (xóa ảnh), §5 (ảnh mờ / nhiều bài / không phải bài toán / Boox PNG / EXIF / chữ chèn lệnh)
- `docs/SPEC.md` US1 (≤ 3 thao tác; nhận ảnh từ camera và file; xác nhận đề ở 100% ca test)
- `docs/DESIGN.md` §7 (ảnh), §9 hàng G3

```ts
// lib/images.ts — every photo is re-encoded on the server: EXIF/GPS gone, rotated upright, sized for Claude.
import "server-only";
import sharp from "sharp";

export const VISION_MAX_EDGE = 1568;
export const VISION_MAX_TOKENS = 1568;
export const MAX_UPLOAD_BYTES = 4 * 1024 * 1024;
const ACCEPTED = new Set(["jpeg", "png", "webp"]);
const tokens = (w: number, h: number) => Math.ceil(w / 28) * Math.ceil(h / 28);

export function fitForVision(w: number, h: number, maxEdge = VISION_MAX_EDGE, maxTokens = VISION_MAX_TOKENS): [number, number] {
  const fits = (a: number, b: number) =>
    Math.ceil(a / 28) * 28 <= maxEdge && Math.ceil(b / 28) * 28 <= maxEdge && tokens(a, b) <= maxTokens;
  if (fits(w, h)) return [w, h];
  if (h > w) { const [rh, rw] = fitForVision(h, w, maxEdge, maxTokens); return [rw, rh]; }
  const ratio = w / h;
  let lo = 1, hi = w;
  while (hi - lo > 1) {
    const mid = (lo + hi) >> 1;
    if (fits(mid, Math.max(1, Math.round(mid / ratio)))) lo = mid; else hi = mid;
  }
  return [lo, Math.max(1, Math.round(lo / ratio))];
}

export async function processImage(input: Uint8Array) {
  if (input.byteLength > MAX_UPLOAD_BYTES) return { ok: false as const, error: "too_big" as const };
  try {
    const img = sharp(input, { failOn: "error", limitInputPixels: 50_000_000 }).rotate(); // upright from EXIF, then EXIF is dropped
    const meta = await img.metadata();
    if (!meta.format || !ACCEPTED.has(meta.format) || !meta.width || !meta.height) return { ok: false as const, error: "not_an_image" as const };
    const turned = (meta.orientation ?? 1) >= 5;
    const [w0, h0] = turned ? [meta.height, meta.width] : [meta.width, meta.height];
    const [width, height] = fitForVision(w0, h0);
    const jpeg = await img.resize(width, height, { fit: "fill" }).flatten({ background: "#ffffff" }).jpeg({ quality: 80, mozjpeg: true }).toBuffer();
    return { ok: true as const, jpeg, width, height };
  } catch {
    return { ok: false as const, error: "not_an_image" as const };
  }
}
```

```ts
import { dateVn } from "@/lib/time";
export const MAX_IMAGES_PER_PROBLEM = 4;
export const MISREAD_LABEL = "Sai chỗ…";
export function misreadCount(msgs: readonly { role: "child" | "tutor"; text: string }[]): number {
  return msgs.filter((m) => m.role === "child" && /^sai chỗ/i.test(m.text.trim())).length;
}
export function deleteAfterVn(now: Date): string {
  const d = new Date(`${dateVn(now)}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() + 90);
  return d.toISOString().slice(0, 10);
}
```
